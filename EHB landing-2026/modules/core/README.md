# modules/core

Core systems: PSS, CRB, STL, DMO, JPS.

- **pss/** – Proof & Security System (KYC, identity, fraud)
- **crb/** – Certification & Registry Board
- **stl/** – Service Trust Level
- **dmo/** – Decentralized Management Office
- **jps/** – Job Profile & Skill
