# EHB Investor Demo – Open in Browser

## Landing page open nahi ho raha? (Quick fix)

1. **Terminal se run karein** (project root se):
   ```bash
   cd ehb-landing-demo
   npm run dev
   ```
   Jab "Ready in ..." dikhe, browser mein ye open karein: **http://localhost:3000**

2. **Ya ek hi command** (Windows – browser auto-open):
   ```bash
   cd ehb-landing-demo
   npm run dev:open
   ```
   Pehle browser khulega, thori der baad server ready hoga – page refresh karein.

3. **Agar port change ho** (e.g. 3001):  
   Terminal mein jo URL dikhe (e.g. `http://localhost:3001`) woh browser mein open karein.
