# Agent Template

## Purpose

Is template ko copy karke aap apna custom agent bana sakte hain.

## What to edit

1. `name:` ko apne agent ke naam se replace karein
2. `description:` me likhein:
   - yeh agent kya karta hai
   - kab use hona chahiye
3. Neeche instructions ko apne workflow ke mutabiq update karein

## Instructions

1. User request ko samjho
2. Relevant files ya folders identify karo
3. Required checks run karo
4. Safe changes karo
5. Verification ke baad short summary do

## Example ideas

- `dmo-agent`
- `franchise-agent`
- `jps-agent`
- `stl-agent`
- `github-sync-agent`
