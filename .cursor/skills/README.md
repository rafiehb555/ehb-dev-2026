# Project Skills

Yahan aap apne project-level custom AI agents/skills rakh sakte hain.

## Folder structure

Har custom skill ka apna folder hota hai:

```text
.cursor/skills/
  your-agent-name/
    SKILL.md
```

## Rules

- Folder name lowercase aur hyphen style me rakhein
- Har skill folder ke andar `SKILL.md` zaroor ho
- Agar chahen to extra files bhi add kar sakte hain:
  - `reference.md`
  - `examples.md`
  - `scripts/`

## Example

```text
.cursor/skills/dmo-agent/
  SKILL.md
  reference.md
```
