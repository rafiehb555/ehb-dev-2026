# INDUSTRY STL IMPACT REFERENCE

> Quick reference: Industry Verification + STL boost system

## STL BOOST TABLE

| Industry | STL Boost | Security Level |
|----------|-----------|----------------|
| Electrical | +5 | High |
| Solar | +5 | High |
| Construction | +4 | High |
| IT/Electronics | +4 | Medium |
| Healthcare | +5 | Premium |
| Legal | +5 | Premium |
| Automotive | +3 | Medium |

## SECURITY LEVELS

- **Basic Secure**: Document upload only
- **Medium Secure**: Documents + on-site audit
- **High Secure**: CRB inspection + certificate
- **Premium Secure**: Multi-audit verification

## STL CALCULATION

```
Final_STL = Base_STL + Sum(Industry_Boosts)
Example: 72 + 5 + 5 = 82 (HIGH)
```

## AUDIT SCHEDULE

- Most industries: 6-month cycle
- Healthcare: 3-month cycle
- Legal: 12-month cycle
- Grace period: 7-14 days

## CARD DISPLAY DATA

- Industry name + badge
- STL boost points
- Security level
- Last/Next audit dates
- Suggested verifications
- Apply button
