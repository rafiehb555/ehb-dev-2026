# DAO Governance Quick Reference

> Hybrid Decentralized Governance

⚠️ **Legal structure review required**

## Governance Structure

```
EHB Foundation (Legal Entity)
└── DMO Governance Layer
    ├── Community Council (Token holders)
    ├── Franchise Council (Franchises)
    └── Core Team Council (Leadership)
```

## Voting Power

| Factor | Weight |
|--------|--------|
| Token Holdings | 40% |
| Contribution Score | 30% |
| Reputation (STL) | 20% |
| Account Age | 10% |

## Proposal Process

```
Submit → Screening (3d) → Discussion (7d) → 
Voting (5d) → Pass/Reject → Implementation
```

## Quorum Requirements

| Type | Quorum | Majority |
|------|--------|----------|
| Feature Update | 5% | 51% |
| Fee Change | 10% | 60% |
| Treasury | 15% | 66% |
| Protocol Change | 25% | 75% |

## DAO Decides

- Ecosystem upgrades
- Reward allocation
- Franchise approvals
- Fee structures

## DAO Does NOT Decide

- Security patches
- Legal compliance
- Individual disputes
