# CRB System Quick Reference

> Central Record Blockchain

## Purpose

CRB verifies and certifies:
- Professionals (doctors, engineers, lawyers)
- Companies (businesses, agencies)
- Products (authenticity, safety)
- Services (quality, standards)

## Certification Process

```
Application → Document Review → Inspection/Test → 
Certificate → DMO Registry → Blockchain Hash
```

## 6-Month Refilling Cycle

Every certification requires renewal:
- Skill retest
- Interview
- Re-inspection
- Performance review

## Non-Compliance Penalties

| Timeline | Action |
|----------|--------|
| Day 1-7 | Reminders |
| Day 15+ | Services hidden |
| Day 30+ | STL downgrade |
| Day 60+ | Suspension |
