# Trust Infrastructure Quick Reference

> PSS + CRB + STL + DMO Integration

## 4 Core Pillars

| System | Role |
|--------|------|
| PSS | Online identity verification |
| CRB | Physical certification |
| STL | AI trust scoring |
| DMO | Central control |

## Trust Flow

```
User/Company → PSS Verification → CRB Certification → 
STL Score → DMO Registry → EHB Services
```

## PSS Functions

- ID verification
- Face verification
- Document verification
- AML screening
- Device intelligence

## CRB Functions

- Professional certification
- Company verification
- Product inspection
- 6-month refilling

## STL Functions

- AI scoring (0-100)
- Search ranking
- Reputation management
- Penalty/reward system

## DMO Functions

- Data management
- Verification control
- Application workflow
- Blockchain records

## Blockchain Layer

Stores:
- Certifications
- Licenses
- Inspection reports
- STL updates
