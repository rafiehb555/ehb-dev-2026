# CRB Inspector App Quick Reference

> Field Verification Mobile Application

## Purpose

Enable CRB inspectors to:
- Conduct professional verification
- Perform company inspections
- Execute product verification
- Complete refilling evaluations

## App Features

1. **Secure Login** - Biometric + device verification
2. **Dashboard** - Tasks, pending, completed
3. **Field Tools** - Scanner, camera, GPS, forms
4. **Evidence Upload** - Photos, videos, documents
5. **Location Verification** - GPS confirmation
6. **Digital Certification** - Generate certificates
7. **Offline Mode** - Works without internet

## Inspection Flow

```
Task Assigned → Visit → Skill Test → 
Evidence Upload → Certification → DMO Registry
```

## Offline Capabilities

- View pre-downloaded tasks
- Capture photos/videos
- Fill forms
- Record GPS
- Auto-sync when online

## Tech Stack

- Framework: React Native / Flutter
- Storage: SQLite / Realm
- Auth: Biometric APIs
- Sync: Background sync
