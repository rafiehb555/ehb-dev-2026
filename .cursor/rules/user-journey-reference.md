# User Journey Quick Reference

> Signup → Income Complete Lifecycle

## Journey Steps

1. **Signup** - Email, phone, password
2. **JPS Profile** - Skills, experience
3. **PSS Verification** - KYC, AML
4. **CRB Certification** - Skill test, inspection
5. **STL Level** - Trust score assigned
6. **Marketplace Listing** - Visible in search
7. **Customer Orders** - Receive bookings
8. **Payments** - Earn income
9. **Reviews** - Customer feedback
10. **Income** - Withdraw earnings

## STL Level Progression

| Level | Score | Requirements |
|-------|-------|--------------|
| Free | 0-30 | Account only |
| Basic | 31-50 | PSS verified |
| Medium | 51-70 | Documents |
| High | 71-85 | CRB certified |
| VIP | 86-100 | Premium |

## Revenue Distribution

| Share | Recipient |
