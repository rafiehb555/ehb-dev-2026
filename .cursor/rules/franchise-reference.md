# EHB Franchise Quick Reference

> Global Franchise Operating Model

## Hierarchy

```
EHB Global HQ
      │
Corporate Franchise (Country)
      │
Master Franchise (Region)
      │
Sub Franchise (City)
      │
Service Providers
```

## Responsibilities

| Level | Key Role |
|-------|----------|
| HQ | Platform, strategy, licensing |
| Corporate | Country ops, compliance, partnerships |
| Master | Regional mgmt, CRB coordination |
| Sub | Onboarding, inspections, support |

## Revenue Split (3% Transaction)

| Recipient | Share |
|-----------|:-----:|
| HQ | 40% |
| Corporate | 25% |
| Master | 20% |
| Sub | 15% |

## Investment Requirements

| Level | Investment |
|-------|------------|
| Corporate | $500K - $1M |
| Master | $100K - $250K |
| Sub | $20K - $50K |

## Provider Onboarding Flow

```
Apply → PSS Check → Sub Franchise
  → CRB Inspection → Certificate
  → DMO Approval → Service Active
```

## Expansion Plan

- Year 1: Pakistan (1 Corp, 5 Master, 50 Sub)
- Year 2: Middle East (3 Corp, 15 Master, 150 Sub)
- Year 3: Global (6 Corp, 50 Master, 500 Sub)
