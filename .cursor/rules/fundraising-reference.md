# Fundraising Strategy Quick Reference

> Multi-Stage Investment Plan

## Funding Stages

| Stage | Amount | Valuation | Purpose |
|-------|--------|-----------|---------|
| Pre-Seed | $500K-2M | $3-10M | Prototype |
| Seed | $3-8M | $15-30M | MVP Launch |
| Series A | $15-40M | $80-150M | Regional |
| Series B+ | $50M+ | $300M-1B | Global |
| IPO | - | - | Public |
