# Trust Card System Quick Reference

> Marketplace Trust Visualization

## Card Types

1. **Service Provider Card** - Individual professionals
2. **Company Card** - Business entities
3. **Product Card** - Verified products

## Card Data Sources

| System | Display |
|--------|---------|
| DMO | Registry ID |
| JPS | Skills, Experience |
| PSS | KYC Status |
| CRB | Certification |
| STL | Trust Level |
| Franchise | Inspector |
| Refilling | Count & Dates |
| Complaints | Total/Resolved |

## Trust Badges

| Badge | Meaning |
|-------|---------|
| 🛡️ | PSS Verified |
| 🏛️ | CRB Certified |
| ⭐ | STL Level |
| 🌐 | DMO Registered |
| 🏢 | Franchise Verified |
| 🔁 | Refilling |
| ⚠️ | Complaints |

## Card Sizes

- **Small** - Search results (Photo, Name, STL, Rating)
- **Medium** - List view (+ badges, refilling, complaints)
- **Full** - Profile page (complete data)
