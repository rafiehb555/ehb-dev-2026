# KYC/KYB Onboarding Reference

> Individual & Business Verification

## KYC vs KYB

| Term | Applies To |
|------|------------|
| KYC | Individuals, professionals |
| KYB | Companies, organizations |

## KYC Steps (Individual)

```
1. Account Registration
2. JPS Profile Creation
3. Identity Verification (ID upload)
4. Liveness Check (selfie)
5. Address Verification
6. AML Screening
7. Risk Scoring
8. DMO Record
9. STL Assignment
```

## KYB Steps (Business)

```
1. Company Registration
2. Document Submission
3. Ownership Verification (Directors, UBO)
4. AML Screening (all parties)
5. Risk Assessment
6. CRB Inspection (if High STL)
7. DMO Registry Entry
8. STL Certification
```

## Required Documents

**Individual:**
- Passport / National ID
- Utility bill / Bank statement

**Business:**
- Incorporation Certificate
- Tax Registration
- Director IDs
- Shareholder Register

## Periodic Refresh

| User Type | Frequency |
|-----------|-----------|
| Low-risk | 24 months |
| Normal | 12 months |
| High-risk | 6 months |
| Business | 6-12 months |

## Decision Outcomes

- Approved (low risk)
- Pending (more docs needed)
- Manual Review (flags detected)
- Rejected (high risk/fraud)
