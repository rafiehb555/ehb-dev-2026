## Service Taxonomy Structure

```
Industry (15 total)
  └── Category (5-8 per industry)
        └── Service (10-15 per category)
```

**Total: 700+ Services**

## Database Tables

```
industries → categories → services
```

## STL Integration
Each service can require minimum STL level:
- Free services (STL: Free)
- Basic services (STL: Basic)
- Premium services (STL: High/VIP)
