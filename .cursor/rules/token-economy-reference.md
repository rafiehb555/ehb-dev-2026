## Token Utilities

| Utility | Description |
|---------|-------------|
| Payments | Pay for services |
| Fees | Verification costs |
| Staking | Boost STL/ranking |
| Rewards | Referrals, activity |
| Governance | Voting rights |

## Token Flow (100 token payment)

```
Platform Treasury: 30% (30 tokens)
Service Provider: 50% (50 tokens)
Franchise: 10% (10 tokens)
Rewards Pool: 10% (10 tokens)
```
