# EHB User Onboarding

## When to Use

- **English:** "Help me understand which PSS role is right for my EHB account"
- **Roman Urdu:** "Mujhe samjhao ke mere liye konsa PSS role sahi hai"
- **Trigger:** New user unsure about role, needs feature requirements, confused about verification steps

---

## Role Selection Logic

EHB has **6 PSS user roles**. Help the user pick based on what they want to do:

| Role | What They Do | STL Max | Verification Required | Time to Verify |
|------|-------------|---------|----------------------|-----------------|
| **Buyer** | Purchase products, hire services | L5 | ID + Liveness + Phone | 5–10 min |
| **Seller** | Sell products, offer services | L9 | ID + Liveness + AML + Address | 15–30 min |
| **Rider** | Deliver orders, transport goods | L8 | ID + Liveness + Address + Device | 10–20 min |
| **Inspector** | Audit products/sites, certify | L10 | All identity + Video interview | 45–60 min |
| **Franchise** | Run geographic hub, hire sub-franchises | L8 | All identity + KYB + Video | 1–2 hours |
| **Admin** | Moderate platform, resolve disputes | L10 | All identity + Face 2FA + Device | 30–45 min |

## Workflow (Step-by-Step)

### Step 1: Understand Their Use Case

Ask the user: **"What do you want to do on EHB?"**

- "Mujhe sirf khareedna hai" (I just want to buy) → **Buyer**
- "Mujhe apna kaam beechna hai" (I want to sell my services) → **Seller** or **Rider**
- "Mera apna company chalani hai" (I want to run a franchise) → **Franchise**
- "Mujhe cheezain check karni hain" (I want to verify/inspect things) → **Inspector**
- "Mujhe EHB par kaam karna hai" (I want to work for EHB) → **Admin**

### Step 2: Explain the Role

Once they choose, explain in **simple Roman Urdu + English**:

**Example for Seller:**
"Ek **Seller** ke tor pe aap:
- Apne products/services list kar sakte ho
- Buyers se orders le sakte ho
- Escrow se paisa nikal sakte ho
- Lekin pehle AP ko KYC verify hona padega — ID, selfie, address proof"

### Step 3: Walk Through Verification

**Each role has mandatory + optional features:**

**Buyer (5–10 min):**
1. ✅ ID Verification (CNIC/Passport) — take photo
2. ✅ Liveness (blink + smile anti-spoofing)
3. ✅ Phone number verification — SMS OTP
4. ⭕ (Optional) Address proof — utility bill (boost to L3)

**Seller (15–30 min):**
1. ✅ ID Verification
2. ✅ Liveness
3. ✅ AML Check (if >50K monthly) — automatic
4. ✅ Address Proof — utility bill or bank statement
5. ⭕ (Optional) Video call — for L8+ boost

**Franchise (1–2 hours):**
1. ✅ ID Verification (director + owner)
2. ✅ Liveness
3. ✅ KYB (Know Your Business) — SECP/company registration check
4. ✅ Address Proof
5. ✅ Video interview — with franchise officer
6. ⭕ Coin lock — depends on tier (Online=0, City=10K, State=50K, Country=100K)

### Step 4: Explain STL Benefits

"Jis qardat verification complete karoge, aapka **STL level badhe ga**:"

- **L1 (Free):** Basic, no verification
- **L2 (Basic):** Phone verified — small purchases OK
- **L3 (Normal):** Full KYC — can list products, normal seller
- **L5 (Advanced):** PSS certified — higher limits, better search rank
- **L8+ (High/VIP):** Franchise/professional — premium visibility

STL jitna **zyada**, utna **zyada kamao** + **kam fees** + **better ranking**.

### Step 5: Next Steps

Tell the user: "Ab jaao aur apna role pick karo. Hum tum ko guide karengy verification se guzarne mein."

## Examples

### Conversation: New Seller (Roman Urdu + English)

**User:** Mujhe GoSellr par apna clothing business shuru karna hai.

**You:** "Shukriya! **Seller** role perfect hai tumhare liye. Yahan kya hoga:
1. Tum apne clothes list kar sakte ho
2. Buyers se orders milenge
3. Paisa escrow se nikal sakte ho
4. Lekin pehle PSS verification karna padega — sirf 20 min lagega.

Verification mein ye features check honge:
- ID (CNIC ya passport)
- Liveness (apna selfie video — blink karo, smile karo)
- Address proof (utility bill ya bank statement)

Ke baad tum **L3 NORMAL** ho jaoge — pehla seller level! Zyada orders → zyada STL → better ranking. Shuruaat karete ho?"

Verification is more thorough:
- ID + Liveness (standard like Seller)

- **Video call with our officer** (30 min) — they ask about experience

Once approved, you'll be **L8+ certified**. High visibility, premium fees. Takes 1–2 hours total. Ready to start?"

- **"Lekin"** = But
- **"Padega"** = Will have to / must
- **"Hoga"** = Will happen
- **"Lagega"** = Will take (time)
- **"Karengy"** = Will do
- **"Jaao"** = Go
- **"Pick karo"** = Choose
- **"Shuru karna"** = Start / begin
- **"Nikal sakte ho"** = Can withdraw / cash out
- **"Utility bill"** = Electricity/water bill

## Verification Tips

- **All users start at L1 FREE** regardless of role
- **Higher verification = higher STL = higher earning potential**
- **Buyers need minimal verification** (just ID + liveness)
- **Sellers + Riders need address proof** (anti-fraud)
- **Franchise + Inspector need video call** (high trust needed)
- **Re-verification** happens per level:
  - L1–3: Annual
  - L4–6: Semi-annual
  - L7+: Quarterly

## Common Questions & Answers

**Q: Mera STL level kya hai?"**
A: "Aap abhi L1 FREE ho. Verification karne se upgrade ho jaoge. Har step → STL up!"

**Q: Can I be multiple roles?**
A: "Haan! Ek same account se Buyer + Seller dono ho sakte ho. Lekin max STL is the LOWEST of all your roles. Agar Buyer verified nahi hai, tum Seller bhi L1 stay karengy."

**Q: How long does verification take?**
A: "Buyer = 5 min, Seller = 20 min, Inspector = 1 hour. Real-time checks → quick approval usually within 24h."
