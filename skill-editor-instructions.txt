## 8 CORE SYSTEMS

### STL (Service Trust Level) — NEVER use "SQL" for this
- 9 levels: L0 FREE → L8 SUPREME
- Master Rule: Final STL = MIN(Product, Seller, Company, Owner)
- If ANY = FREE → Final = FREE
- Score bands: 0-20 FREE, 21-40 BASIC, 41-60 NORMAL, 61-75 STANDARD, 76-85 ADVANCED, 86-92 HIGH, 93-96 PRO, 97-98 VIP, 99 ELITE, 100 SUPREME
- 4 STL types: PSS-STL, CRB-STL, DMO-STL, EHB-STL (master)
- Inputs: PSS + CRB + DMO + Wallet coin lock + Complaints
- Coin locks: L2=20, L5=200, L8=2000, L9=4000, L10=10000+ EHBGC
- STL formula in services/api/stl-replit/services/stlService.js — NEVER modify without running npm run test:stl (58 tests must pass)

### PSS (Personal Security System)
- KYC: Unverified → Basic → Fully Verified
- Trust score 0-100 (KYC + profile + complaints + behavior)
- Complaint system: Low=warning, Medium=penalty, High=restriction

### CRB (Certification & Registry Board) — NEVER use "EDR" for this
- Verifications: Basic → Advanced → Expert → Master
- Exam system: category-based, multiple difficulty levels
- Refill system: periodic renewal, expiry windows
- Multimedia proofs: video/image/docs, blockchain hash storage

### DMO (Decentralized Management Office)
- 8-step user flow: Registration → KYC → Verification → CRB → STL Assessment → Activation → Review → L8 Application
- Policy management, approval workflows, franchise governance

### Finance/Wallet
- EHB Wallet with EHBGC (EHB Global Coin)
- Revenue split: Platform 40% / Service Provider 25% / Franchise 20% / Affiliate 15%
- Escrow system for secure transactions

### Franchise System
- Hierarchy: Country → Corporate → Sub Franchise
- Territory-based, performance tracking, revenue sharing

### JPS (Job Profile & Skill)
- AI-powered job matching, skill radar charts

### AI Department
- Recommendation, fraud detection, legal AI, medical diagnosis, tutoring
- AI widget: always visible bottom-right, text + voice input
