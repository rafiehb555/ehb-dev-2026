# Frontend Starter

This folder is reserved for the future EHB frontend application.

Recommended stack:

- Next.js for full-stack React development
- React for reusable UI components

Recommended future folders:

- `app/` or `pages/`
- `components/`
- `services/`
- `hooks/`
- `styles/`

Before building frontend features:

1. Read the docs in `../docs/`
2. Read `../prompts/frontend_rules.txt`
3. Check `../tasks/current_tasks.md`
