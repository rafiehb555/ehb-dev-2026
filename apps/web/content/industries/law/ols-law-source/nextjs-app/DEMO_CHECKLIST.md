## BACKUP PLANS

### If Voice Doesn't Work
```
Action: Switch to text input immediately
Say: "Let me type this to show you clearly"
```

### If Page Loads Slowly
```
Action: Have screenshot backup ready
Say: "While this loads, let me explain the feature..."
```

### If Asked Technical Questions
```
Say: "Great question! Our architecture is designed for scale. 
I'd be happy to arrange a technical deep-dive with our team."
```

### If Demo Crashes
```
Action: Refresh browser
Say: "Let me refresh - this sometimes happens with live demos"
Continue: Move to next screen if needed
```
