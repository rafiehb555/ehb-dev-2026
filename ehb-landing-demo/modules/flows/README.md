# modules/flows

User and Provider lifecycle flows.

- **user/** – Signup → PSS → JPS → CRB → STL → Service access
- **provider/** – Signup → PSS → CRB → STL → DMO listing → Orders → Payments

Use for auth, onboarding, and flow-specific components/hooks.
