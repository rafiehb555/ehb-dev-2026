## ⭐ NAMING CONVENTION RULE (MANDATORY — APPLY EVERYWHERE)

### Rule:
> Wherever a short name appears in UI, docs, or code — ALWAYS write:
> **FULL NAME (SHORT-NAME)**

### Examples:
```
✅ CORRECT:
  EHB-STL-LEVEL (Service Trust Level)
  EHB-DMO (Decentralized Management Office)
  EHB-JPS (Job Profile & Skill)
  EHB-PSS (Proof & Security System)
  EHB-CRB (Central Record Blockchain)
  GoSellr GSM (Global Shopping Management)

❌ WRONG:
  STL
  DMO
  JPS
  Just writing the short name alone
```

### Where to Apply:
- All UI pages (titles, headings, badges, cards)
- All documentation
- All API responses (where human-readable names appear)
- All dashboard labels
- Navigation menus
- Error messages
- Notifications
