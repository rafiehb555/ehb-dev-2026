## SECTION 9: EHB-CRB (Certification & Registry Board)

### What It Is:
Physical world verification via inspectors. Gives users real-world trust credibility.

### CRB Flow:
```
User applies for CRB →
DMO routes to random Sub Franchise (anti-corruption) →
Never same franchise twice →
Inspector assigned →
Physical visit (GPS tracked, photos geotagged) →
Report submitted →
Sub → Master → Corporate → DMO approval chain →
Certificate issued → STL boost
```

### CRB Certificate Levels:
| Level | STL Boost | Eligibility |
|-------|-----------|-------------|
| Basic | +5 | L2 users |
| Standard | +10 | L3 users |
| Advanced | +15 | L4 users |
| VIP | +20 | L5 users |

### Anti-Corruption Rules:
1. Never same franchise twice for same user
2. Inspector cannot inspect someone they know (AI conflict check)
3. Blind assignment (no pre-knowledge)
4. All steps logged with timestamp + blockchain hash

### Refilling Schedule:
| CRB Level | Valid For |
|-----------|----------|
| Basic | 6 months |
| Standard | 1 year |
| Advanced | 18 months |
| VIP | 2 years |
