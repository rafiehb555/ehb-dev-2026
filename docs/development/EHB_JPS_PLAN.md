## PART 1: WHAT IS JPS

**JPS (Job Provider System)** is EHB's AI-powered hiring, skill, and workforce management platform.

> Simple line: "LinkedIn + Upwork + Coursera + HR department — all AI-powered, trust-verified"

**JPS Role in EHB:**
- Every person on EHB has a JPS profile (mandatory)
- JPS connects: Employers ↔ Job Seekers ↔ Skill Providers
- Designations are merit-based (6-month contracts, competition-driven)
- JPS data feeds directly into STL score

## PART 4: 6-MONTH CONTRACT SYSTEM (UNIVERSAL)

### Applies To ALL Roles:
- Job employees (all designations)
- Franchise operators (all levels)
- Sellers (license renewal)
- Riders (performance review)
- Inspectors (performance + exam)

### Contract Lifecycle:
```
Appointment / Hiring
        ↓
6-Month Active Contract
        ↓
Month 5: Renewal Notice Sent
        ↓
Evaluation Window Opens
        ↓
All Candidates Submit:
  → Knowledge Exam (AI-proctored)
  → CRB Physical Inspection
  → Performance Score Review
  → Complaint Ratio Check
        ↓
AI Ranks All Candidates
        ↓
Top Scorer → Keeps / Gets Seat
2nd Place → Offered lower designation (L-1)
Failed → Removed, reapply after 30 days
        ↓
New 6-Month Contract Begins
```

### Evaluation Criteria (Weighted):
| Criterion | Weight |
|-----------|--------|
| Knowledge Exam Score | 30% |
| AI Performance Score | 30% |
| CRB Inspection Result | 20% |
| Complaint Ratio | 10% |
| STL Score | 10% |

### Competition Rules:
1. Multiple candidates can compete for same seat
2. Current holder has NO advantage over challenger (merit only)
3. Failing exam = automatic removal
4. 3 consecutive contract failures = 90-day ban from that designation level
5. Exceptional performance = early promotion review after 3 months

### Exam System:
```
Exam Triggered (Day 150 of contract)
        ↓
AI Generates Questions (industry-specific + role-specific)
        ↓
Candidate takes exam (browser-locked, AI proctored)
        ↓
Auto-scored (MCQ) + AI-reviewed (short answers)
        ↓
Score recorded in JPS + STL history
```

## PART 5: SALARY STRUCTURE

### 4-Component Salary System:

```
Total Earnings = Fixed Salary + Performance Bonus + STL Bonus + Commission
```

### Component Details:

| Component | Basis | Range |
|-----------|-------|-------|
| Fixed Salary | Designation level + industry | Defined in salary bands |
| Performance Bonus | AI score (0-100) | 0% to 30% of fixed |
| STL Bonus | STL level (L1–L5) | 0% to 20% of fixed |
| Commission | Sales/referral/service | Role-specific % |

## PART 6: AI MATCHING SYSTEM

### How JPS AI Matches Candidates to Jobs:

```
Employer Posts Job
        ↓
AI Extracts Requirements:
  - Skills required
  - Experience level
  - Industry
  - Location preference
  - STL minimum
  - Education requirement
        ↓
AI Scores All Candidates:
  - Skill match %
  - Experience match %
  - STL score
  - PSS verification
  - CRB status
  - Past performance
  - Education + certifications
        ↓
AI Generates Ranked Shortlist
        ↓
Employer Reviews Top 10
        ↓
Interview Scheduling (in-platform)
        ↓
Offer + Contract via Platform
        ↓
6-Month Clock Starts
```

### Matching Algorithm Variables:
| Variable | Weight in Match |
|----------|----------------|
| Skill match | 30% |
| Experience level | 20% |
| STL score | 15% |
| Location proximity | 10% |
| Education match | 10% |
| Performance history | 10% |
| CRB verification | 5% |

### AI Smart Features:
- **Career Gap Analysis** — Detects employment gaps, flags for context
- **Skill Gap Detection** — Tells candidate which skills to add
- **Growth Predictor** — Projects candidate's likely level in 12/24 months
- **Fraud Detection** — Detects fake experience/degree claims
- **Job Fit Score** — 0–100 match score for every application

## PART 14: ADVANCED BONUS FEATURES

### 1. Talent Pool System
- Employer can "Follow" a candidate (talent pipeline)
- AI notifies employer when followed candidate becomes available
- Candidate can opt-out of employer follow

### 2. Blind Application Mode
- Candidate applies without name/photo shown
- Only skills/scores shown initially
- Reduces hiring bias

### 3. Skill Auction
- In-demand candidates can receive competing offers
- AI manages "bidding window" (48 hours)
- Platform takes 0% cut (employer pays full offer)

### 4. Team Matching
- Employer defines entire team structure needed
- AI matches full team (not just individuals)
- Ensures role compatibility across team members

### 5. Remote Work Trust Score
- Sub-score within JPS for remote workers
- Based on: task completion, communication response time, meeting attendance, output quality
- Employers can filter by Remote Trust Score

### 6. Cross-Country Matching
- Pakistani talent matched to UK employers (Phase 2)
- Visa sponsorship flag in job posts
- Platform handles compliance checks (country-specific)

### 7. JPS Leaderboard
- Top performers per industry per month
- Public ranking (opt-in)
- Top 10 get featured in platform discovery

## PART 16: API ROUTES PLAN

```
# Profile
GET    /api/jps/profile              → Get own JPS profile
PATCH  /api/jps/profile              → Update profile
GET    /api/jps/profile/[userId]     → View public profile

# Skills
POST   /api/jps/skills               → Add skill
POST   /api/jps/skills/verify        → Submit for verification
GET    /api/jps/skills               → List all skills

# Jobs
GET    /api/jps/jobs                 → Browse jobs (AI ranked)
POST   /api/jps/jobs                 → Post a job (employer)
GET    /api/jps/jobs/[id]            → Job detail
POST   /api/jps/jobs/[id]/apply      → Apply for job
GET    /api/jps/applications         → My applications
GET    /api/jps/employer/applications → Employer: incoming applications

# AI Matching
GET    /api/jps/ai/match/[jobId]     → AI match score for job
GET    /api/jps/ai/career-path       → AI career suggestions
GET    /api/jps/ai/skill-gap         → Skill gap analysis

# Contracts
GET    /api/jps/contracts            → My contracts
GET    /api/jps/contracts/active     → Active contract details
POST   /api/jps/contracts/renew      → Apply for renewal

# Exams
POST   /api/jps/exams/start          → Start designation exam
POST   /api/jps/exams/submit         → Submit answers
GET    /api/jps/exams/history        → Exam history

# Courses
GET    /api/jps/courses              → Browse courses
POST   /api/jps/courses              → Provider: create course
POST   /api/jps/courses/[id]/enroll  → Enroll in course
POST   /api/jps/courses/[id]/complete → Complete + get certificate

# DMO
GET    /api/dmo/jps/contracts        → All active contracts
PATCH  /api/dmo/jps/contracts/[id]   → Override / terminate
GET    /api/dmo/jps/exams            → All exam results
GET    /api/dmo/jps/leaderboard      → JPS top performers
```
