## PART 1: WHAT IS EHB AFFILIATE

**EHB Affiliate System** enables users to earn commissions by referring new users, sellers, franchise applicants, and job seekers to the platform.

**Key Principle:** Affiliate earns from the platform's share — NOT from the seller or buyer.

> "Refer someone → they transact → you earn automatically, forever"

## PART 3: AFFILIATE TIERS (LEVEL STRUCTURE)

### 4-Level Affiliate Network:
```
You (Affiliate L1)
        ↓ referred by you
Your Referrals (Level 1 Network)
        ↓ referred by your referrals
Level 2 Network
        ↓
Level 3 Network
        ↓
Level 4 Network (capped here)
```

### Earnings Per Level:
| Level | Relationship | Commission % |
|-------|-------------|-------------|
| L1 | Directly referred by you | 5% |
| L2 | Referred by your referrals | 2% |
| L3 | Referred by L2 | 1% |
| L4 | Referred by L3 | 0.5% |

*Commission % is taken from EHB's platform share (10% of each order), NOT from seller's 70%.*

### Earnings Example (Order = PKR 10,000):
```
Order Value: PKR 10,000
EHB Platform Share: 10% = PKR 1,000

If referred by Affiliate A (L1):
  → A earns: 5% of PKR 1,000 = PKR 50
  → A's referrer (L2 above A): 2% = PKR 20
  → And so on up the chain

Seller still gets PKR 7,000 (70% unchanged)
```

## PART 5: HOW AFFILIATE TRACKING WORKS

### Referral Link System:
```
Every user gets unique affiliate link:
https://ehb.io/join?ref=RAFI2026

Link Tracking:
  → Click recorded (IP + device)
  → Cookie set (30-day attribution window)
  → New user registers → linked to affiliate
  → All future transactions auto-credited
```

### Attribution Rules:
- **Last click wins:** If user clicks multiple affiliate links, last link gets credit
- **Attribution window:** 30 days (click must lead to registration within 30 days)
- **Permanent link:** Once user registered via your link, they are yours forever
- **Self-referral blocked:** Cannot refer yourself or use own link
- **Fraud detection:** Coordinated self-referral rings detected by AI

## PART 8: AFFILIATE PAYMENT RULES

### Payment Method:
- All affiliate earnings → Trusty Wallet (EHBGC)
- Auto-credited within 24 hours of eligible transaction
- Held in "Pending" for 48 hours (dispute window)
- Then moved to "Available" balance

### Clawback Rules:
- If referred user gets refunded → Affiliate earning reversed
- If referred user account banned → Earnings from that user frozen
- If affiliate suspected of fraud → All pending earnings held

## PART 9: FRAUD PREVENTION

### Affiliate Fraud Types + Detection:
| Fraud Type | Detection Method | Action |
|------------|-----------------|--------|
| Self-referral | Same device/IP + account | Block + -20 STL |
| Fake account farming | Same IP, bulk registrations | AI flags + review |
| Click fraud (bots) | Bot pattern detection | Links disabled |
| Commission abuse (deposit/withdraw) | Transaction pattern | Capped + flagged |
| Colluding fraud ring | Graph analysis (shared devices) | Ring banned |

### Anti-Fraud Rules:
1. Earning capped at 20 EHBGC/day from deposit referrals (anti-washing)
2. Referral must make at least 1 real purchase for affiliate to earn
3. Referral must have different device fingerprint from affiliate
4. 5+ referrals from same IP in 24hrs → flagged for review

## PART 10: BLOCKCHAIN AFFILIATE EARNING

### How Blockchain Helps:
- Every affiliate commission recorded on-chain (for high-value transactions)
- Affiliate can prove earnings history to third parties (e.g., banks)
- Transparent ledger: affiliate knows exactly why they earned what
- Cannot be manually altered by anyone

### Blockchain Records:
```
AffiliateTransaction {
  affiliateId
  sourceUserId (who triggered it)
  orderId / eventId
  level (L1/L2/L3/L4)
  commissionEHBGC
  txHash (on-chain)
  timestamp
}
```

## PART 11: FRANCHISE + AFFILIATE SYNERGY

### Franchise Operators as Super Affiliates:
- Sub Franchise auto-earns from ALL sellers/buyers in their area
- This is the franchise's 3% — separate from user affiliate
- Sub Franchise can ALSO participate as regular affiliate (for users outside their area)
- Avoids conflict of interest: franchise earning = area-based, affiliate = link-based

### Affiliate → Franchise Path:
```
Affiliate builds big network in an area
        ↓
Platform suggests: "Apply for Sub Franchise"
        ↓
Franchise gives more earning + more control
        ↓
Affiliate network converts to franchise network
        ↓
Earning increases significantly
```
