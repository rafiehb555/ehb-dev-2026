# Data Collection Guide - EHB Project

## Yeh file guide hai ke kaunsa data kahan save hoga

---

## 1. Project Overview (`.cursor/rules/project-context.md`)
Yahan add karein:
- Project ka naam aur description
- Company ka background
- Main objective/goal
- Target users kaun hain

---

## 2. Requirements (`docs/requirements/`)
- Business requirements
- User stories
- Acceptance criteria
- Constraints/limitations

---

## 3. Features (`docs/features/`)
Har major feature ke liye alag file:
- Feature name
- Description
- User flow
- Edge cases

---

## 4. Database (`docs/database/`)
- Entity list (Users, Products, Orders, etc.)
- Relationships
- Schema design
- Sample data

---

## 5. API (`docs/api/`)
- Endpoints list
- Request/Response formats
- Authentication
- Error handling

---

## Kaise Data Share Karein?

ChatGPT se copy karke yahan paste karein:

1. **Direct chat mein** - Main khud relevant file mein save kar dunga
2. **Category batao** - "Yeh database schema hai" ya "Yeh feature list hai"
3. **Ek ek karke** - Organized rahega

---

## Shuru Karein!

Ab ap data share karna shuru karein. Main automatically:
- Relevant file mein save karunga
- Organize karunga
- Future chats mein use karunga
