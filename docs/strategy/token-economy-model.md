# TOKEN UTILITIES

## 1. Platform Payments

Users pay for services using tokens:

| Use Case | Description |
|----------|-------------|
| Service Booking | Pay service providers |
| Product Purchase | Buy marketplace items |
| Subscriptions | Premium memberships |
| Verification Fees | PSS/CRB processing |

---

## 2. Verification Fees

| Fee Type | Purpose |
|----------|---------|
| KYC Processing | Identity verification |
| CRB Certification | Physical inspection |
| Document Authentication | Certificate verification |
| License Application | Government services |

---

## 3. Staking Benefits

Service providers stake tokens for benefits:

| Stake Amount | STL Boost | Search Ranking | Withdrawal Limit |
|-------------|-----------|----------------|------------------|
| 100 tokens | +5% | +10% | $5,000/day |
| 500 tokens | +15% | +25% | $25,000/day |
| 2000 tokens | +30% | +50% | Unlimited |

---

## 4. Rewards Program

Users earn tokens through:

| Activity | Reward |
|----------|--------|
| Referral (user signs up) | 10 tokens |
| Referral (user completes KYC) | 25 tokens |
| Complete service | 2% of transaction |
| Verified review | 5 tokens |
| Report fraud (confirmed) | 50 tokens |
