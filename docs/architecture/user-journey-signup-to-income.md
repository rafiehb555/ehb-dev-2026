# STEP 1 — USER SIGNUP

User registers on EHB platform:

| Field | Required |
|-------|----------|
| Email | ✅ |
| Phone | ✅ |
| Password | ✅ |
| Name | ✅ |

**System Action:**
- DMO creates basic account
- User receives verification email/SMS
- Account status: `Active (Unverified)`

**STL Level:** Free (0-30)

---

# STEP 2 — JPS PROFILE CREATION

User completes professional profile:

| Section | Details |
|---------|---------|
| Profession | Electrician, Doctor, Developer, etc. |
| Skills | Specific skills (wiring, diagnosis, coding) |
| Experience | Years, companies, projects |
| Education | Degrees, institutions, years |
| Portfolio | Past work, images, descriptions |

**Example Profile:**
```
Name: Ali Khan
Profession: Electrician
Experience: 5 years
Skills: Wiring, Solar Installation, AC Repair
Education: Technical Diploma
```

---

# STEP 3 — PSS VERIFICATION (KYC)

Identity verification process:

| Check | Method |
|-------|--------|
| ID Verification | Upload ID card/passport |
| Liveness | Selfie with blink/smile |
| AML Screening | Sanctions/PEP check |
| Address | Utility bill upload |

**Result:**
- Verified Identity ✅
- Risk Score: Low/Medium/High
- Compliance: Cleared

**STL Level Upgrade:** Basic (31-50)

---

# STEP 4 — CRB CERTIFICATION

For service providers:

| Step | Activity |
|------|----------|
| Application | Submit certification request |
| Document Review | CRB reviews credentials |
| Skill Test | Technical/practical exam |
| Interview | Professional interview |
| Inspection | Workplace verification |

**Result:**
- CRB Certificate issued
- Certification valid for 6 months
- Added to DMO registry

**STL Level Upgrade:** High (71-85)

---

# STEP 5 — STL TRUST LEVEL ASSIGNMENT

AI calculates trust score:

| Factor | Weight |
|--------|--------|
| Verification Status | 20% |
| Certification Status | 25% |
| Performance History | 15% |
| Customer Reviews | 15% |
| Complaints | 10% |
| Refilling Results | 15% |

**STL Levels:**

| Level | Score | Benefits |
|-------|-------|----------|
| Free | 0-30 | Basic access |
| Basic | 31-50 | Limited visibility |
| Medium | 51-70 | Standard ranking |
| High | 71-85 | Priority ranking |
| VIP | 86-100 | Top ranking + badges |

---

# STEP 7 — CUSTOMER SEARCH & REQUEST

Customer searches for service:

```
Search: "Electrician near me"
```

**AI Matching:**
1. Skill matching
2. Location proximity
3. STL ranking
4. Availability check

**Results (ranked by STL):**
1. VIP providers (86-100)
2. High STL (71-85)
3. Medium STL (51-70)
4. Basic STL (31-50)
5. Free (0-30)

---

# STEP 8 — SERVICE BOOKING

Customer books service:

```
Customer → Selects Provider → Confirms Time → 
Payment Hold → Provider Accepts → Service Scheduled
```

---

# STEP 9 — SERVICE DELIVERY

Provider delivers service:

```
Provider Arrives → Work Performed → 
Customer Confirms → Service Complete
```

---

# STEP 10 — PAYMENT

Payment processed via EHB Wallet:

| Share | Amount | Recipient |
|-------|--------|-----------|
| Service Provider | 70% | Provider wallet |
| Platform Fee | 20% | EHB |
| Franchise | 10% | Local franchise |

**Example:**
```
Service Cost: PKR 10,000

Distribution:
- Provider: PKR 7,000
- Platform: PKR 2,000
- Franchise: PKR 1,000
```

# 6-MONTH REFILLING (CONTINUOUS)

Every 6 months, maintain certification:

```
Refilling Due → Skill Re-test → Interview → 
Inspection → Pass/Fail → STL Update
```

**If failed:**
- 7-day warning
- Services hidden
- STL downgrade
